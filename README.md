# World Modulator

一个 SillyTavern 扩展，用来**实时调制角色扮演世界的规则与角色状态**。

它独立于主模型运行：每轮正文结束后自动调用一个分析模型，解析出世界状态、世界规则、角色档案与衣柜的变化，把这些内容按需注入回主模型的提示词。你负责决定世界应该是什么样，它负责让主模型始终记得。

---

## 功能

### 世界状态
自动追踪当前时间、当前位置、当前天气，随时间推进自动更新。

### 世界规则
两种写入方式：

- **直接新增** —— 你自己写清规则，立即生效。适合需要精确控制的场合。
- **规则待办** —— 只写个大概想法，攒成待办清单，然后选择：
  - **插入输入框**：拼成文本送进酒馆输入栏，你可以接着编辑再发送。
  - **直接补充规则**：不进输入框，直接交给分析模型整理成正式规则并写回规则表。

分析模型**只识别 {{user}} 明确下达的增删改指令**，正文里的场景描写、角色对话、旁白设定都不会被当作规则变动。

被删除或停用的规则会进入「已失效规则」记录，注入时明确告知主模型它不再生效——避免主模型继续按旧规则叙事。

### 角色档案
两套字段规格，可随时切换：

- **简化版**（18 项）：身份、年龄、身高、罩杯、种族、性交次数、和 user 的关系、母猪评级、好感度、好感度阶段、性格、背景、淫乱化程度、性癖喜好、心理想法、整体服饰、整体身材、怀孕情况。
- **正常版**（28 项）：在上面的基础上细分服饰（上衣和下衣 / 腿部服饰 / 内衣 / 足部服饰 / 道具或配饰）与身材（身材 / 胸部 / 屁股 / 腿部），并增加是否经过精神调教、特殊性技、规则影响。

母猪评级采用 N / R / SR / SSR / I 五档体系，按种族、社会地位、外貌、才能、血统、影响力综合评定。

### 角色衣柜
记录角色的历史穿着，每次换装追加一条。

- 两级折叠：点角色名展开记录列表，点单条看完整描述。
- 每条可编辑、可删除，也可手动补录。
- 服装描述按部位逐项要求（头饰 / 上衣 / 下衣 / 内衣 / 腿部 / 足部 / 配饰），含颜色、材质、款式、贴合度。
- 注入时告知主模型「历史穿着为角色拥有的衣物，可自行按需切换组合」。

### 推荐规则
每轮根据当前剧情生成 6 条情色向规则建议：3 条贴合当前剧情走向，3 条跳脱颠覆。可直接采纳进规则库。

### 提示词注入
世界状态、规则、角色档案、衣柜、调制器说明，**每一项都有独立开关**，可自由选择注入哪些。

调制器说明是给主模型的能力设定：它描述 {{user}} 拥有无视物理法则强制修改世界的能力，被修改的事物会立即按新规则运行且认知被直接替换。这段说明被 `<World Modulator>` 标签包裹。

注入顺序固定为：调制器说明 → 世界状态 → 世界规则 → 角色档案 → 衣柜。

### 跨卡搬运
列出其他角色卡里创建过的规则、角色与衣柜，展开后点任意条目即可复制到当前卡生效。

### 数据管理
- **导出**：全部设置、规则、角色、衣柜、待办导出为 JSON（含 API Key，请妥善保管）。
- **导入**：从导出的 JSON 恢复，删插件或换浏览器后可一键导回。

### 界面
- **悬浮球**：可拖动，点击展开主面板。
- **魔杖菜单**：从酒馆的扩展菜单进入。
- **主题**：内置两套皮肤——深空蓝（霓虹青 / 深色玻璃）与液态磨砂玻璃（靛蓝 / 实心磨砂，边缘透光）。

## 安装

### 方式一：Git 安装（推荐）

在 SillyTavern 的「扩展」页面点「Install Extension」，填入：

```
https://github.com/Mjbajj/st-World-Modulator
```

### 方式二：手动安装

把整个仓库目录放到：

```
SillyTavern/data/default-user/extensions/third-party/st-World-Modulator/
```

确保 `manifest.json` 和 `index.js` 在该目录的**根层级**，然后重启 SillyTavern。

## 使用

### 1. 配置分析模型

打开面板 → **设置** → **分析模型**：

| 选项 | 说明 |
|---|---|
| API 模式 | `复用主模型配置` 会读取酒馆当前的自定义（兼容）通道；`独立配置` 需填地址与 Key |
| 配置组 | 可保存多套连接设置（地址 / Key / 模型 / 温度），下拉即可切换 |
| 模型列表 | 填好地址和 Key 后点「拉取」，选中即为该配置使用的模型 |
| 使用预设 | 可套用酒馆里的现有预设，并逐条开关预设内的提示词 |
| 温度 | 建议 0.2 ~ 0.4，分析任务不需要太高的发散性 |
| 超时 | 单次请求超时秒数 |

### 2. 开启需要的追踪项

**设置 → 追踪项目**：世界状态、世界规则、推荐规则、角色衣柜，四项独立开关。

衣柜需要单独开启——开启后才会从正文自动记录穿着。

### 3. 选择注入内容

**注入** 页逐项开关，决定哪些内容发给主模型。

建议：调制器说明、世界状态、世界规则、角色档案保持开启；衣柜内容较长，按需开启。

### 4. 打开自动分析

面板顶部的「分析」开关打开后，每次主模型输出完成且内容稳定时自动触发分析。

也可以随时点「立即分析」手动触发。

## 工作方式

```
主模型输出正文
      ↓
判定内容是否稳定（连续 1.4 秒无变化）
      ↓
组装载荷：最近消息 + 已有状态 + 系统提示词
      ↓
调用分析模型 → 返回 JSON
      ↓
应用到状态（世界状态 / 规则 / 角色 / 衣柜）
      ↓
重新注入提示词 → 主模型下一轮看到新状态
```

采用轮询而非事件触发，是因为流式输出期间消息是半成品，直接分析会得到残缺结果。稳定判定窗口可在设置中调整。

---

## 已知限制

- **分析模型需要支持 JSON 输出。** 若模型返回的不是合法 JSON，插件会追问一次；仍失败则本轮作废。
- **衣柜去重基于文本比对。** 描述完全相同且时间、场合也相同的记录会被跳过。如果你确实需要记录两条几乎一样的穿着，在描述里做点区分即可。
- **跨卡搬运是单向的**，只支持把别处的数据复制到当前卡。
- 面板部分内容（如待办、跨卡列表）需要切换到对应标签页才会刷新。
